04 Process

How a project works with me

A simple, transparent process, so you always know what’s happening and what comes next.

  1. 01

    Understand

    We talk about your business, your customers and what the website needs to do. I’ll ask what pages, text and photos you already have.

    You get An agreed list of pages and goals

  2. 02

    Plan & design

    I outline the pages and suggest a visual direction (layout, colours and type), then share it for your feedback before building anything.

    You get A design direction to approve

  3. 03

    Build

    I hand-code the site in HTML, CSS and JavaScript, checking it at phone, tablet and desktop sizes as I go, and keep you updated at the points we agree on.

    You get Clear updates on progress

  4. 04

    Review & launch

    We review it together and I make the agreed changes. Then I publish it, for example on GitHub Pages, and hand over all the files.

    You get A live website and its source files

05 Skills

Tools I work with

The tools behind my published work, each with an example of where I used it in the Ember & Oak concept project.

  • HTML

    Semantic, five-page site structure with landmarks, a skip link and a clear heading order.

  • CSS

    Shared design tokens, flexible grid layouts and subtle animations that respect reduced-motion settings.

  • JavaScript

    An accessible mobile menu, keyboard-friendly menu tabs, a photo lightbox and a live “open now” status.

  • Responsive design

    Layouts checked from small phones up to wide desktops, with navigation and most content still usable without JavaScript; only the full menu list needs it.

  • Git & GitHub

    Version history built in small, clearly described commits, stored on GitHub.

  • GitHub Pages

    Published the finished site so it’s live and viewable at a public link.
